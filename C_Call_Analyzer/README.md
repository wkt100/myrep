# C语言工程调用关系分析工具

## 功能介绍

这是一个强大的C语言工程调用关系分析工具，可以帮助开发者快速理解大型C语言项目的结构和函数调用关系。工具具有以下核心功能：

1. **自动扫描** - 递归扫描指定目录下所有C语言源文件(.c/.h)
2. **函数解析** - 提取所有函数定义及其所在文件和行号信息
3. **调用关系分析** - 分析函数之间的调用关系
4. **按文件分组显示** - 按源文件路径组织和显示函数定义和调用关系
5. **可视化支持** - 生成DOT格式的调用图，支持使用Graphviz工具转换为可视化图表

## 系统要求

- Python 3.6 或更高版本
- 无需安装额外的Python第三方库（仅使用标准库）
- 如需将DOT格式转换为可视化图表，可安装 Graphviz（可选）

## 使用方法

### 基本使用

在命令行中运行以下命令分析默认目录（当前目录）：

```bash
python analyze_c_calls.py
```

### 指定目录分析

使用 `-d` 或 `--dir` 参数指定要分析的目录：

```bash
python analyze_c_calls.py -d path/to/your/c/project
```

### 分析示例代码

要分析提供的示例代码，可以运行：

```bash
python analyze_c_calls.py -d examples/src
```

## 输出文件

工具运行后会生成以下文件：

1. **call_relations.txt** - 详细的函数调用关系报告，按文件分组显示
2. **call_graph.dot** - DOT格式的函数调用关系图

## 报告格式说明

### 函数定义清单部分

报告中"按文件分组的函数定义清单"部分显示了每个源文件中定义的函数：

```
[examples/src/Log.c] - 包含 10 个函数
--------------------------------------------------------------------------------
  LogInit                         | 行号: 45
  LogWrite                        | 行号: 67
  LogClose                        | 行号: 98
  ...
```

### 函数调用关系部分

"按文件分组的函数调用关系"部分显示了每个源文件中函数的调用关系：

```
[examples/src/hzPanel1a.c]
--------------------------------------------------------------------------------
  InitPanel 调用了:
    -> LogWrite [examples/src/Log.c]
    -> CreateContainer [examples/src/container.c]
    ...
```

## 可视化调用图

生成的DOT格式调用图可以使用Graphviz工具转换为PNG等格式的图片：

### 安装Graphviz

**Windows**: 从 [Graphviz官网](https://graphviz.org/download/) 下载安装程序

**Linux**: 
```bash
sudo apt-get install graphviz  # Ubuntu/Debian
sudo yum install graphviz      # CentOS/RHEL
```

**macOS**: 
```bash
brew install graphviz
```

### 生成可视化图表

```bash
dot -Tpng call_graph.dot -o call_graph.png
```

生成的图片中，不同源文件的函数会被组织在不同的子图中，便于直观查看代码结构。

## 高级特性

### 按文件分组

工具会自动按照源文件路径对函数进行分组，使分析大型项目时更加清晰。分组信息在报告和DOT调用图中都会体现。

### 函数定位

每个函数都会显示其在源文件中的行号，方便开发者快速定位到具体代码位置。

### 跨文件调用显示

调用关系中会显示被调用函数所在的源文件路径，帮助理解跨文件的依赖关系。

## 注意事项

1. **解析限制** - 工具使用正则表达式进行函数定义和调用解析，对于特别复杂或非标准的C语法可能解析不完全

2. **关键字过滤** - 工具会自动过滤C语言关键字和控制流语句，避免将它们误认为是函数

3. **大项目处理** - 对于非常大的项目，分析过程可能需要较长时间，生成的报告文件也会很大

4. **内存使用** - 大型项目分析时可能会消耗较多内存，建议在有足够内存的环境中运行

## 故障排除

### 未找到函数调用关系

如果报告中显示"未找到函数调用关系"，可能有以下原因：
- 源代码结构不符合预期格式
- 函数调用形式过于复杂
- 可以尝试修改源代码中的函数定义格式，确保符合标准C语法

### 解析错误

如果在解析特定文件时出现错误：
- 检查该文件是否有特殊的编码或格式问题
- 文件编码应尽量使用UTF-8格式
