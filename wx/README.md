个人每日执行系统 (Personal Execution System)

这是一个基于微信小程序云开发构建的“行为驱动型”个人管理工具。它不同于传统的待办清单（To-Do List），更侧重于目标聚焦、执行跟踪与数据复盘。

🌟 设计理念

三件要事制：强制用户每日仅设定 3 个最重要的目标，避免贪多嚼不快，确保精力聚焦。

完成标准定义：任务必须包含明确的“完成标准”，将模糊的目标具象化。

强制复盘逻辑：任务未达成必须记录原因，通过数据驱动行为优化。

可视化反馈：通过完成率看板和历史色彩矩阵，直观展现个人执行力的成长。

🛠 技术架构

前端框架：微信小程序原生开发框架 (WXML / WXSS / JavaScript)

后端服务：微信云开发 (WeChat Cloud Development)

云数据库 (JSON DB)：存储任务、时间块及每日总结数据。

云权限控制：基于 OpenID 的数据隔离，确保个人数据私密安全。

核心组件：自定义卡片式 UI、TabBar 导航系统、数据聚合分析逻辑。

📂 功能模块

1. 今日执行 (Today)

任务管理：每日限额 3 条，支持设定标题与交付标准。

状态流转：支持“待处理 -> 执行中 -> 已完成/已失效”的完整生命周期管理。

实时统计：自动计算今日当前的执行完成率。

2. 执行历史 (History)

时间线视图：按日期倒序排列，回顾过往每日表现。

色彩等级：

🟢 绿色：完成率 >= 80% (高效执行)

🟡 黄色：完成率 >= 50% (基本合格)

🔴 红色：完成率 < 50% (亟需复盘)

3. 数据分析 (Analysis)

核心指标：累计坚持天数、总任务数、平均完成率。

行为洞察：分析失败任务的共同原因，定位个人执行力瓶颈。

🚀 快速开始

环境准备：

下载并安装 微信开发者工具。

申请小程序 AppID。

配置云环境：

点击工具栏“云开发”按钮，开通环境。

在云数据库中手动创建三个集合：tasks, time_blocks, daily_summaries。

在 miniprogram/app.js 中填入你的环境 ID。

运行项目：

导入项目源码，点击“编译”即可在模拟器查看效果。

📝 数据库集合说明 (Schema)

tasks: _id, title, standard, status, date, createdAt, failReason

daily_summaries: _id, date, completionRate, focusScore, biggestProblem

# 执行系统 2.0 升级建议清单

### 1. 心理暗示强化 (UI/UX)

-   **任务仪式感**：点击完成时，触发手机短震动 `wx.vibrateShort()`。
-   **动态名言**：在首页顶部随机显示一句话（如：“专注于最重要的事，其他的都是噪音”）。

### 2. 深度分析 (Data)

-   **能量曲线**：在 `daily_summaries` 集合中记录“完成任务时的心情（1-5星）”。
-   **时间块地图**：统计你通常在一天中的哪个时段最容易完成“三件事”。

### 3. 云开发高级应用

-   **订阅消息**：每天早上 8:00 自动发送微信通知，提醒你填写今日三件事。
-   **自动存档**：使用云函数，在每天凌晨 4 点自动将未完成的任务标记为“失败”。

### 4. 社交/监督（可选）

-   **搭档系统**：允许输入另一个人的环境 ID，互相查看对方的完成率（不看内容，只看百分比）。
